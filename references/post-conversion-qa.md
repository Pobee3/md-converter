# 成稿质检与局部重解析

适用于已生成 `source.md`、`blocks.json`、`source_map.json` 和来源快照的转换任务。它是交付前的原文复核流程；当前执行器没有自动语义校对、自动局部择优或由成稿一键重解析的命令，以下步骤由助手组织。不得把语言模型的通顺度判断当作原文证据。

## 找出可疑处

按章节顺序覆盖所选范围的全部块，分段读取成稿，保留相邻块和跨页上下文。以 `blocks.json` 的 ID 与字符范围记录疑点，不用易变的 Markdown 行号作永久定位。将两类检查并行进行：

- **从成稿找问题：** 标记替代字符、异常乱码、断词/连字符、明显重复或跳接、句子中断、上下文突变、多栏顺序可疑、标题或注号混入正文、脚注调用与注文本脱节、数字/符号/专名不一致。语义不顺只产生候选；古语、专业术语、作者原有断裂和编校体例不能因此被改写。
- **从原件找遗漏：** 对照目标 PDF 页清单、原始解析块、被排除块、页面图和输出块覆盖，检查文字密集页却没有对应正文、原页图表/注释未进入成稿、两栏或页边文字被漏读。完整 Markdown 本身无法揭示完全缺失的一段，因此不能只做成稿语言检查。EPUB 对照原生 spine/DOM 节点覆盖。

另做两项全范围强制检查：

- **字符空白：** 扫描连续单字母或短字母片段、词内空格、断行连字符残留、标点前空格和异常宽分隔。每一候选都回到原页；原书疏排要恢复为连续词形并另存样式证据，OCR 拆字要修正，真实词间空格保持不变。仅用全局删除空格会破坏真实词界，禁止作为修复方法。
- **每一处换页边界：** 按物理页顺序核对上一页最后一个正文块与下一页第一个正文块，不只检查程序预先标出的候选。若属于同一段或同一句，合并 block 并保留跨页 fragments；不得让批次边界、页眉页脚删除或 PDF 换页制造新段落。

为每条候选保存 `source_revision`、疑点类型、块 ID、规范化块文本中的 Unicode 半开字符范围、前后文、可疑字符串、发现方式和待核状态。若疑似整段遗漏而没有块 ID，从 PDF 文件页或 EPUB 原生位置登记；不要伪造段落 ID。重复出现的同一文本按实际来源区域分别记录。可把这些记录保存在任务私有质检日志中，不私自扩展公共契约。

## 回到来源并选择解析方式

有块 ID 时用 `locate` 取其全部来源片段，再以 PDF 文件页、`bbox`、原始块索引和相邻页定位；一段可能跨页。页级反查 `pdf-page:<文件页>` 会返回多个块，须再核对区域和文字，不把同页当成精确命中。没有块 ID 的漏段候选从原页区域向输出块反查。原始 PDF 与其 SHA 快照是最终定位基准；OCR 版若改变页数、裁边、旋转或几何，必须先建立并验证到原件的页/区域对应，不能直接替换来源身份。

先并排核对原页图、现有 Standard 结果与 PDF 原生文字层；按问题选最小必要范围。文字或版面仍不清楚时，对受影响页/区域运行一轮 Advanced，或用独立本地 OCR、放大裁图对照。相邻页只用于判断续段、续注和阅读顺序。保留所有候选的工具/模型版本、原始输出、来源页/区域及差异；Advanced 或 OCR 输出不同不自动代表更正确。复杂图表、公式与注号须对照原页视觉证据，不能靠上下文补写数字或符号。

## 回写和复验

只有原页证据足以支持时，才通过现有私有审阅决定修正文字、分类、排除、段落拆分/合并或原注关系；记录 before/after、原页位置和取舍依据，重新适配受影响范围。不要直接修改 `source.md` 后让 `source_map` 指向旧文字。重识别可能改变块边界：先核对旧来源证据，能证明同一实体才保留 ID；拆并段按身份迁移规则处理，不能强贴旧 ID。

每次回写后重新运行 `validate`，并对改动块及相邻块重复成稿检查和 Markdown→原页→Markdown 反查。记录疑点为已证实修正、原文如此/误报或仍未解决；仅对受影响处复验，不因少量样本通过而宣称全文校读完成。常规疑点只做一轮 Advanced；随后改用独立证据或保留疑点，避免反复运行同一模型。交付前要求字符空白候选全部关闭，并为每个相邻正文页边界留下审阅决定；任一项仍未解决时，质量状态保持 `needs_review`，不得称为已完成或 `reviewed`。交付时按 PDF 文件页列出其他未解决项、已试过的方式和映射精度；EPUB 列原生位置。
