# 原文标注版导出

规范原文仍是 `来源包/source.md`，其段落 ID、字符范围和来源映射不能因阅读排版而改写。标注版是从 `blocks.json`、`source_map.json`、`page_map.json` 和 `notes.json` 派生的副本。

## 询问与输出

独立任务开始时连同保存位置、翻译意向问用户选择原文阅读版格式：MD、PDF、Word、EPUB，可多选；用户不指定就用 MD。不要求用户选择排版参数。默认保存来源包、轻量增强型 MD、交接索引与 MD 阅读版；只有用户明确选择 Word、PDF 或 EPUB 时，才启动相应排版和成品检查。`save --layout split --formats md,word` 在 `阅读原文/标注版/` 输出所选格式；`export-reading 来源包 新文件夹 --name 名称 --formats ...` 适用于已有来源包。输出文件夹必须新建或为空，不覆盖旧版。

Word 与 PDF 使用同一份来源行和标注规则分别排版。Word 用 `python-docx` 制作并通过 LibreOffice 渲染预览；PDF 用 ReportLab 嵌入可用的宋体或 CJK 衬线字体，以免中文页码标题在字体回退时丢字。执行前通过 Codex workspace dependencies 查找 Python 与所需库；Word 的 `--soffice` 可指定 LibreOffice。PDF 在常见系统字体路径查找 CJK 衬线字体，必要时通过 `MD_CONVERTER_PDF_FONT` 指定 TTF/TTC 路径，TTC 还可设置 `MD_CONVERTER_PDF_FONT_SUBFONT`。MD/EPUB 不以 Word 为中间格式。对 Word 成品依 documents Skill 做渲染与逐页视觉检查；对 PDF 也检查实际页面。若字体、注号、图表、公式、页面或长段不正确，修订后重新生成，不把抽样通过当成整本文字已核准。

非 MD 阅读版依据 `toc.json` 的已核章节及实际正文起点生成可点击目录。Word/PDF 的目录标题和阅读页码都链接到相应正文锚点；页码用动态交叉引用，PDF 转换后须确认文字与页码链接仍在且跳到正确阅读页。EPUB 的阅读器导航和文内目录也链接到章节起点；目录中的已核印刷页码与标题共享同一链接。EPUB 会重排，没有固定阅读页码，不以设备分页伪造数字。选章或试样只列实际输出中可到达的章节；章首页未收入试样时，链接指向试样内该章的第一块，页码也以该块为准。找不到正文锚点的条目不能做空链接或跳到目录页。抽查目录首、中、末及同一原页上的不同章起点。

## 标注规则

翻译交接默认使用 `scripts/export_translation_md.py 来源包 翻译输入/原文增强.md --title 书名`。可用 `--source-id-file` 限定已校定范围；原件不在来源包内时用 `--original` 指定已核 PDF/EPUB。脚本按 `blocks.json` 的稳定 ID 和逻辑段落、`source_map.json` 的片段、`page_map.json` 的已核印刷页、`notes.json` 的身份与引用生成轻量增强型 MD；正文段首及跨页续段仍在同一段内标注。每块前的 HTML 注释仅携带稳定 ID 和块类型；精确字符范围、PDF 页/区域及核验状态留在来源包的 `source_map.json`，由交接索引记录路径和指纹。正文页码标记可点击原 PDF 页。原注编号及其正文引用能唯一对应时生成双向锚点，不能唯一绑定的原注保留并在交接索引列为未链接，不猜测。

增强型 MD 的 frontmatter 记录文献 ID、原文版本、规范 `source.md` 与原件相对路径和指纹、质量状态。字号等排版要求在需要非 MD 导出时读取，不触发提前排版。它是方便翻译 Skill 消费的派生输入，不回写规范原文，不把可见页码标记当作待翻译词句。翻译 Skill 以每个 `source-block` 为对齐单元，通过交接索引读取精确映射，保留原注来源身份；译文 MD 与 `alignment.json` 另存。PDF/Word 的阅读页码只能在排版后生成，不能预写入增强型 MD。EPUB 无 PDF 物理页时不伪造页码。输出后核查每个锚点、链接目标、相对原件路径与指纹，并用不同来源包回归验证，不按某五页的具体页码写规则。

- 每个逻辑段落只出现一次起始标记 `[S.印刷页码/PDF文件页-该物理页段落序数]`。标题不算正文段落。跨页续段在续页实际起点前加同式标记，但不新建段落；**续页标记与段首标记同字号、同字体、同基线**。原页把一个词从中间截开时，将标记放在完整词前，避免拆词。
- 每个涉及的来源页在标注版只出现一次 `印刷页码/PDF页码：x/y`，与段落标记 `[S.x/y-段落序数]` 保持相同的数字顺序。页眉式标签便于查页，页内精确边界以段内续页标记和 `source_map.json` 为准。选择中途五页时，纳入完整跨页段落所需的相邻页文字。
- 印刷页码未核实则写 `?`；EPUB 没有固定 PDF 文件页时不创造页码。原书页码、PDF 文件页和阅读版分页是三种不同的编号。
- 标题和正文统一使用宋体；缺少宋体的设备以相近的衬线字体回退。正文段落两端对齐。MD 使用 `<p style="text-align: justify">`；若阅读器过滤 HTML 样式，只能保证其文本标注与映射，需换支持该样式的阅读器确认排版。Word/PDF 阅读页右下角显示阿拉伯数字，EPUB 阅读器分页由设备控制，不伪造固定阅读页码。
- 原注保留为原注，不新增 AI 译注。试样只带入与已选来源块有关的注释；阅读版按已核责任显示作者注、原版译者注、编者注、校注，未能判定时明确写“责任未明的原注”，保留原编号与正文中的注号。当前导出器在正文之后集中列出原注，不能声称恢复了原 PDF 页脚的精确位置；跨页续注的完整性仍须对照原页核验。Word/PDF/EPUB 的图表、公式和行内资源若尚不能由当前导出器忠实表达，先停止该格式导出，按原件逐项处理后再交付；不能以文字占位替代原内容。MD 仍保留原始 Markdown 块与资产。

## 非 MD 成品的三处预览

每次实际导出 Word 或 PDF，按次序从**实际成品的阅读页**展示目录第一页、随机选出的中间正文一页、带原注的一页。`导出记录.json` 记录阅读总页数、每页角色、页号和 `抽样预览/reading-page-N.png`。原件没有目录或原注、成品不足三页时明确记录缺项与替代页，不把替代页标成原注页。EPUB 可重排，只展示对应三处内容位置而不报告固定阅读页。若用户要求修改，修订后再导出并重新选择；每次结果留在新的输出文件夹。内部仍应检查全部阅读页的溢出、缺字、错序、注释和段落连续性。

## 当前执行器边界

`scripts/export_reading.py` 已验证普通 PDF 正文、标题、跨页段落的四格式输出。它不会自动修复 OCR、判断标题或决定跨页续段；这些决定必须先由助手对照 PDF 原页作出，再重建来源包。它对复杂视觉块采取阻断而不是默默丢弃。更复杂的版面可以由助手沿用同一标注规则另做格式专用排版，并保存导出记录与预览。
