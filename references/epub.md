# EPUB 原生结构与定位

适用于 EPUB。使用 MinerU 4 Flash 原生适配，结合 EPUB 原始 DOM 检查结构；不走 PDF OCR。实际 Flash 输出能力需按 [运行能力](runtime.md) 核验。

## 输入和原目录

读取容器、OPF manifest、spine、EPUB 3 nav 或 EPUB 2 NCX 与资源。验证压缩包成员路径、资源引用、文件规模、损坏与加密；不执行书内脚本或获取远程资源。字体混淆与正文 DRM 需区分，不能因为存在 encryption.xml 就认定正文不可读；合法文档声明也不等于危险实体。

spine 是内容文件顺序，不是章节列表。按 nav/NCX 目标和原章标题建立 chapter_id、层级与范围，支持一个 spine 文件多章、一章跨多个文件。保留 non-linear 项及其作用，不把尾注文件当普通正文章，不静默丢弃附录。

用户只确认原目录/位置与全书或选章范围。没有目录时保留有依据的标题候选并明确未确认；不能以 filename 伪装作者章名。

## 内容提取

沿 DOM 保留强调、上下标、代码/预格式文本、段内换行、列表层级与链接位置。先确定块与行内结构，再生成 Markdown；不能先 join 全部 itertext 再靠字符串替换恢复链接。同样文字的两个链接可以指向不同目标。

图片保留资源和原图关系；SVG、MathML、复杂 HTML 表格不能因简单渲染器不支持就丢弃，也不执行活动内容。不可靠的复杂结构保留原始内容与渲染证据，按当前契约可表达范围输出；无题注图的非空 text 限制见 [契约边界](output-contract.md)。

用 EPUB noteref、footnote/endnote 等原生语义建立注释关系，核对所有引用和回链。它们仅说明引用或位置，不证明作者身份。注释责任归属按 [内容保真](fidelity.md) 处理。

选章同时收集被引用的章外尾注和必需资源，记录为依赖，不能悄悄扩充全书正文范围。孤立注释保留原始证据并列未决，不因为没有引用就删除。范围表达尚受当前契约限制时保留候选，不能声称无缺漏生产发布。

## 稳定位置

每个片段记录 0-based spine_index、href、element_id、range 和 evidence；CFI 仅在可验证时填写，否则 null。没有元素 ID 时降级并保存可审查的文本/结构证据。不要向原附件写入生成的 ID；生成身份属于转换注册表。

更改字号后的屏幕页不作为印刷页。page-list 只有明确版次和证据才转换为印刷标签；否则保留原始候选。不同格式的同名书不天然共用页码或 document_id。

当前 0.2.0 page_map Schema 只接受 PDF，与 EPUB 固定输出要求有冲突。CR 未接受前可以解析和核验候选，**不得伪造 PDF 页图或声称已完成契约兼容的 EPUB 正式发布**。详见 [输出契约](output-contract.md)。
