# PDF 解析与原页核对

适用于 PDF；原注、图表和修订见 [内容保真](fidelity.md)，文件与状态见 [输出契约](output-contract.md)。以下是适配器必须满足的步骤，不能凭本文宣称本机已具备解析能力。

## 预扫描与范围

记录输入 SHA-256、物理页数、加密/损坏、旋转、原始几何、PageLabels 和书签。每个文件页建立 page_map 条目，包括封面与空白页。不要修改原 PDF 或原附件。

印刷页码必须有可核查的来源。优先记录原页实见数字；对于无印刷数字的空白页，若同一编号分区的上下页均有可靠页码，PDF 页序连续、两端页码差恰与中间文件页数相符，且没有编号重置、插页、漏扫或双页扫描，才可唯一补出中间书页码。内部把这种值标为 inferred，保存上下页及原页证据，不冒称原页印有数字。原目录、PageLabels 和邻页偏移单独只能产生候选。识别 roman/arabic/other、edition_id 和 sequence_id；编号重置、漏扫、重复、错序、双页扫描分别列异常。无法确定记 unknown。原版页边码另存 edition_markers，不能混入当前版印刷页。

内部把完整目录目标与实际章标题核对，保存原目录树及异常定位。给用户确认页码时只集中展示原目录首页、每个大章节首页，以及附录区、参考文献或引用区（若有）首页；表格仅列章节、原书印刷页码和 PDF 文件页，可将页码链接到原页。不要在用户表格中逐项写“未印出”等内部标签。完整目录可供查看与选章，不让用户逐项核对小节。大章节按原目录的主要层级确定。PDF 书签可能是读者自加标签或错误拼接文字，只能先作为候选；原书目录以印刷目录和实际标题共同核验。章首页隐藏页码时，目录提示须结合同分区邻页证据或其他原页证据，才能成为书页码；内部仍区别实见与推得。无目录时提供明确物理范围，不凭主题自动生成原目录。选章范围应包含目标原注、图表和必要上下文；目标覆盖与边界上下文分开记录。用户已选择全书时不再询问是否只做一章。

## 目录候选与正文定位

私有审阅记录区分原书印刷目录条目、正文识别出的标题、人工补录和 PDF 书签候选，保存每项来源、原页证据、采纳/仅保留标题/排除的决定与理由。正文标题不因字样相似就自动成为目录节点；原目录条目也须找到与之对应的实际正文起点。保留原书层级和顺序；调整父级或排序时检查是否成环、重复或越出上级范围。此审阅记录不是新增公共字段，正式 `toc.json` 仍按现行契约写入。

每个采纳的章节分别保存：目录上标示的页码提示、章首页书页码的实见或唯一推得结果及证据、PDF 文件页、正文起点锚点及其证据。章首页无可见数字时记录原页观察，不填无证据的猜测值；符合前述相邻页条件时可补出书页码。起点尽量定位到原页中的标题块或文字范围；有可靠几何时记录区域，无法精确定位时保留页级或待核验状态。PDF 文件页从 1 起；解析器的 0-based `page_idx`、阅读器 PageLabel 和印刷页码各自转换或保存，双页扫描还需区分同一文件页内的左右原页。不能用全书固定偏移或孤立目录提示推算，也不能把同页不同章合成同一起点。

按正文起点和目录层级检查章节范围：下一同级章节的起点构成当前章节上界，子章须落在父章内，跨页与同页边界都要核对；缺失起点时不要据猜测裁切选章。用户确认页码对应关系只确认展示的核对点，不替代这些内部正文锚点检查。

展示页码对应关系前，从所涉编号分区的非边界内部页随机抽取三页，逐页查看原页上的可见印刷页码，并与各自 PDF 文件页核对。保存可复现的抽样方法、样本页、原页证据和核对结果；若抽中无可见页码，保留该结果并补抽，直到取得三页可核对样本。抽样发现错位、编号重置或异常时，扩大相关区段检查并向用户说明；三页抽查不能替代逐页 page_map 的证据状态。

当前执行器的 `inspect-pdf` 返回每章文件页、PageLabels、已审的可见印刷页及每项证据。书签缺失或不符原件时，转换助手可先对照原目录和章标题制作私有 `toc_catalog`（章节 key、标题、父级、原文件页、同页起点与原页证据）；不是要求用户填写文件页。`convert-pdf --chapter-id` 会计算页集合并在同页起止处按已核对的章节位置裁切块。若同页位置不能确定，拒绝将候选边界当成精确选章；输出仍保留待核验信息。目录确认和印刷页确认互相独立。

## Standard 适配

本地 MinerU 4 走 Standard。先核对实际版本帮助；已观察到 mineru-kit parse 的 --tier、--pages、--format、--output 选项。可用输出包括 middle_json，但字段适配和资产提取仍须实际小样验证。

全书或选定范围先评估一次性解析：依据文件页数与版面复杂度、代表性小样耗时、可用内存、模型/服务限制、单次任务时限和失败后的可恢复性，记录采用单次或分批的理由。可行时让 `convert-pdf` 的单个批次覆盖整个目标范围，不把“全书”偷换为首批；单次成功仍须逐页检查覆盖并运行同样的目录、段落和资源验证。若超时、内存不足或服务拒绝，先查询原 job 状态并保留已完成结果，确认没有重复运行的任务后再调整为分批；批大小进入检查点配置，变更时须保留旧任务并建立有记录的新计划，不改写旧检查点。不得只因单次失败就盲目重交整本。评估已表明单次不可靠时直接分批，不为形式上的“一次性”消耗整本处理时间。

用完整输入快照做范围解析，保留原页身份。明确区分 CLI 传入页码与解析结果的页索引；检查非第一页起始的小样，确认输出索引是原文件偏移还是批内序号。不得仅凭索引变量名加 1。若不得不做输入切片，必须保留切片到原文件页的证据映射。

保存实际调用参数、引擎/模型版本和来源、耗时、原始结果与资源。后续修正阅读顺序或注释关系时优先复用这些结果，不因译法变化重跑转换。

先用小样测资源；需要分批时按输入与环境确定批大小，不把临时批大小说成 MinerU 固定上限。相邻批次可带重叠页供段落边界核对；重叠的解析片段与正式目标页分别计数。

## 局部 Advanced 与证据选择

复核候选包括多栏顺序冲突、段落/脚注截断、表格行列或符号缺失、复杂公式、页码与目录不符。自动检测提出疑点，不自动把置信度转换为 verified。先检查 PDF 原生文字层与 MinerU 结果；对扫描、低质文字、特殊字体或复杂版面，按页或区域调用可用的本地 OCR、增强裁图或其他合适的读取方式。对照原页图选择，保留全部候选和转换记录；替换文字时不改变 PDF 文件页身份。

在同一源文件范围运行 Advanced，默认一轮补跑；需要时再用独立 OCR 或文字层。保存 Standard、Advanced、补充读取候选和差异。将候选与对应原页/局部图并排核对：文字、顺序、注号、数字、符号、上下标与图表结构。选择结果及依据写入审阅记录；无法确定则保留疑点及 PDF 文件页码。没有新的可验证依据不反复重试，也不把“模型输出一致”当作真实正确。

普通未决项可在保留原件和可读内容的前提下进入待校读稿；缺关键页、正文无法还原或严重断链阻止完成，集中报告实际问题。最终报告单独列出仍有疑点的 PDF 文件页码，附疑点类型和已用的复核方法；处理中不要求用户逐页裁决。

有行号的学术版需另检页边行号是否混入正文、数字是否导致假分段。行号不是页码或原版页边码。检测结果只是疑点，不按正则批量删除数字；局部修订必须绑定原块、Unicode 范围、before/after 和原页证据。Advanced 也可能把正文误判为列表，不能因其重组了结构就接受。

原注可以跨页，也可能多个注号被引擎合并为一块。已核验拆分用不同 note_id 保留同一原始区域及各自原始 span 范围；未验证的续注/拆分关系保留未决。显式署名（如德文末尾“— Anm. d. Hrsg.”）可作为编者注证据；无署名不能只按位置推定身份。

对作者注、编者注、原译者注、校勘注和身份未知的原注分别核对：注号、注文本起止、跨页续注、正文每次调用点、责任身份依据以及原页区域。不得仅凭脚注位置推定责任主体；缺失或多义调用点进入该 PDF 页的疑点清单。图表核对原页裁剪边界、完整题注/图例、表格行列与数字、正文引用；复杂表可先保留可读原页图，但不能称其结构已转录准确。

## 跨页与坐标

逻辑段落合并依靠版面顺序、续行/断句、章边界及注释区域证据。来源片段可以跨物理页，一个 source_id 对应多个 fragment_id。重叠批片段按同一来源证据去重，重复文字不直接删除。

逐页排查空白、缺块、页眉页脚误入、栏序和跨页断句；对同页章界、跨页段落、注释和图表做双向原位核验。能够证明的段落边界才合并或拆分，不能因模型一次输出为一块就认定是一个自然段。原页某区域找不到 Markdown 对应内容、或 Markdown 来源区域与原页不符时，先修复再交付；无法修复时明确降级并列出 PDF 页码。

range 严格按实际 blocks.text 的 Unicode code point 半开区间计算，不含外部锚点。本实现的 blocks.text 是规范化 Markdown 块，保留在块中的样式语法也参与计数；不能混用渲染后纯文本下标。验证范围连续、无越界、覆盖正确；人为插入的空格/修订必须有明确规范化依据和记录。

bbox 使用旋转后的可视页，左上原点，0 到 1 归一化。保留原始几何转换证据；未验证坐标转换时用 null，不用默认整页框冒充段落定位。调整逻辑阅读顺序不得重编号 pdf_page。
