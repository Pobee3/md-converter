# 原文 原注与图表保真

## 文字与身份

原始文本与版面证据优先。明确 OCR 错字、页眉页脚去除、断行连字符修复需保存 before/after、来源位置、依据与审阅结果；不确定词保留疑点，不因译文需要而润色或补全原文。审阅说明、工具说明、个人笔记和导读不写入 source.md。

### 字符间空白与疏排

普通空格只表示原文的词间边界，不用来模拟字距、疏排或逐字强调。检查并回核连续单字母/短字母片段、词根或音节被空格拆开、行末断词残留、连字符两侧异常空格、标点前空格及其他疑似词内空白。修正必须由原页字形、同页文字层或独立 OCR 支持，不能仅凭语言模型认为某个词更通顺。

原书以疏排或加大字距强调一个词时，规范文本保存连续词形；强调属于版式信息。若现行输出能在不污染 `blocks.text` 字符范围和来源映射的前提下表示强调，使用该表示；否则将样式及原页位置保存在任务私有审阅证据中。不得把 `W o r t` 一类人为插入的空格保留为规范正文。

### 跨页逻辑段落

段落按原书逻辑和版式识别，不按 PDF 文件页切分。每个相邻正文页边界都检查上一页最后一个正文块与下一页第一个正文块，并结合缩进、段首格式、终止标点、断行连字符、栏序和句法判断。页末未完句、下一页无新段起势，或原页明确显示续段时，合并为一个逻辑段落；标题、列表或明确新段格式则保留边界。证据不充分时登记待核，不猜测。

同一跨页段落只保留一个 `source_id`，每一物理页区域各用一个 `fragment_id` 和准确字符范围定位。规范文本只在真实词间加入一个空格；跨页拆开的同一单词去掉排版连字符和换页空白，原文真实连字符则保留。页界不写成 Markdown 段落分隔，物理页位置由 `source_map.json` 和 `page_map.json` 表达。

永久 ID 随首次确认逻辑实体生成并持久登记，不由页码、MD 行号、数组下标或文本 hash 直接生成。排序变化使用 order。跨页是同一段的不同 fragments；相同文字可能是两处独立段落。

重 OCR 先对旧来源证据匹配；无法确定时不强行贴旧 ID。拆并段涉及 id_migration 与审阅，旧 release 和笔记仍可打开，失配由下游标 orphaned。未实现迁移时明确停在候选阶段。

## 原有注释

所有源注 origin=original_document。placement 表示 footnote/endnote/inline/marginal；responsibility 使用 author/original_translator/editor/critical_apparatus/other/unknown。校勘性质可同时用 apparatus_kind=critical 与 agent_role=editor 表达。

按原书前言、编辑体例、署名与明确标签确认责任主体。仅有位置或解释性语气不足以确认；未知保持 unknown。不要沿用历史示例中 translator/textual/publisher 等未获契约接受的枚举。

保留 original_label 原样，支持数字、字母、撇号和星号。同号注用各自 note_id 区分；同一注全部引用与重复出现都应保留。夹注需判断是否属于作者正文，不因括号形式直接移出正文。复杂校勘保存可可靠取得的 lemma、variant、witness 证据，正式字段不支持时留原始记录并提案，不能私自加字段。

原注可读表示与结构化 notes 对应；后续译注不改变源责任身份。无法对应引用或遗漏源注必须进入覆盖报告；当前精确出现位置、孤立注和注文本来源的契约缺口见 [输出契约](output-contract.md)。

## 图 表与公式

| 对象 | 保留 | 重点核对 |
|---|---|---|
| 表格 | 原图/原页证据与可靠 HTML/JSON 结构；复杂表不强压 Markdown | 行列头、合并单元格、单位、负号、小数位、样本量、显著性与脚注 |
| 数据图 | 原图、坐标轴、图例、图注和正文引用 | 不猜点位、不重绘曲线；复合图先保留整体和子图标签 |
| 普通图 | 原资源或有依据的原页裁剪、图号与图注 | 不因无文字说明就丢图；保留来源 |
| 公式 | 编号、原图证据、可靠 LaTeX/原生 MathML | 上下标、希腊字母、矩阵、正负号及正文式号引用 |

执行三类检查：文件是否存在可读取；编号、题注、引用和结构是否完整；关键数字、公式和疑难文字是否与原页一致。第三类只对实际核对对象作结论，不能由资产 hash 推导内容准确。

结构不可确认时保留原图并明确 unresolved，不编表格数据。EPUB 原生结构的渲染截图是派生证据，不冒称出版社提供的原图；资产角色需要契约可表达。

## 交叉引用

正文“见表 2”“式 (3)”“第 4 节”保留原字串并连接可确定的目标 block_id；文献引用连接 bibliographic_key。未解析仍可搜索原字符串，报告 unresolved。内部资源或链接缺失与语义引用未解析分别判断；严重断链阻止 completed，不把所有未解析引用自动视为无关紧要。
