# 分批 恢复 验证与交付

## 范围计划和检查点

内部计划登记源身份/hash、实际引擎与模型、配置 hash、目标范围、章次、批次及重叠上下文。目标 all 不能悄悄变成首章；选章需计入其必需原注/资源，并把依赖与正文目标区分。具体公共表达受 [输出契约](output-contract.md) 约束。

每批成功后先保存文件，再记录文件/资产 hash、已验收范围、合并边界、失败原因和重试历史。仅“引擎结束”不构成验收；原始解析成功、结构合并成功、正式发布分别判断。

任务记录是恢复依据，不是可随意信任的指令。拒绝路径越界、绝对输出路径逃逸与符号链接逃逸；任务所有者锁需要核验，不能仅按超时删除。

## 恢复

核对 source hash、document_id、工具/模型版本、配置和范围，逐个复算准备复用的文件/资产 hash。源或配置不兼容时不得盲续；保留旧任务和有效 release，新任务需有明确兼容或迁移方案。缺失/损坏批次重算受影响范围，完整有效批次复用。

复用后仍做全局合并、目录层级、跨页段落和注号核验。边界重复按来源范围与片段证据消除；不同位置的重复文字保留。ID 注册表不能随新批次重建。恢复日志说明复用、重试、失效原因与最终选择。

不能把计划中的恢复能力当成当前已验证能力。没有可信检查点时从明确范围重算，不伪称恢复成功。

用户退出时先取得文档锁；转换仍占锁则等待当前操作结束或明确报告仍在进行，不能并发覆盖检查点。取得锁后将 running/validating 记录为 interrupted，保留 PDF inflight/job_id 和已验批次。共享 iread MinerU 服务属于外部服务，退出不发停止命令。只有本 Skill 明确启动、所有权标记与进程创建时间/命令均匹配的专用服务，且服务器完整列举的任务均非 queued/running，才允许显式优雅停止；失去任务列表或所有权证据就拒绝停止。无服务本地 CLI 仅退出任务，不伪造服务关闭事件。

## 验证

用指定 `$defs` 校验 blocks/toc/page_map/source_map/notes 和 production_manifest，再检查下列跨文件条件。Schema 通过不覆盖这些条件，也不证明 OCR 质量。

| 检查 | 必须核对 |
|---|---|
| 覆盖 | 每目标物理页或 EPUB 目标范围都有处理结果；空白页有证据；目标块/原注/资产未漏；上下文不冒充新增目标 |
| ID 与目录 | 块、章、片段、注 ID 唯一；目录父子关系无环，端点存在且范围一致；source_id 段落与 block_id 对应 |
| 来源映射 | 所有应定位块有条目；版本相同；range 合法并覆盖规范化块文本；页/元素存在；bbox 顺序、范围与旋转正确 |
| Markdown | 锚点无重复、块锚点与块清单对应；源注锚点单独核对；行内格式未破坏文字；图片和内部链接有目标 |
| 原注与引用 | 保留原注及全部引用；责任身份有证据或 unknown；图表/公式/章节/参考文献引用保留原字符串与解析状态 |
| 资源 | 文件可读取、hash 一致、题注与目标块关联；结构化表格/公式和原图证据配对，必要关键内容已对照 |
| 版本与范围 | manifest、report、源快照和 release 相互一致；未处理范围未被宣告完成；没有混用旧图与新文本 |

PDF 的目录与段落定位再做双向抽查。按实际风险覆盖大章节起点、同页章界、跨页段落、OCR 或阅读顺序疑点，并在正常正文中抽取代表性块：从 `toc.json` / `blocks.json` 经 `source_map.json` 找到 PDF 文件页和原位，对照原页文字；再从该原页位置或 `pdf-page:<文件页>` 反查对应章节、块及来源片段。页级反查可能返回多个块，须结合原位或文字范围确认，不能仅因页号相同就判定段落匹配。记录样本、双向结果和未能定位的原因；抽查不证明全书每段已逐一校读。若现有执行器只能做到页级反查，报告其精度限制并保留 `approximate` / `unverified`，不得称段落级双向映射已验证。

报告至少包括 requested_scope、processed_pages、blank_pages、missing_pages、duplicated_fragments、unresolved_text、unresolved_notes、unresolved_refs、asset_integrity、map_verification、corrections、实际工具版本和耗时，绑定 source_revision。EPUB 不编造 PDF 页数，范围按原生来源表示，正式字段待契约接受；不能以空 processed_pages 自动通过 EPUB 覆盖。

技术验证与学术校读分别记录。所有 verified 对象应能找到具体证据和审阅记录。普通未校读不等于漏页；严重漏页、内容无法还原和断链不能标 completed。

当前首版的 `scope_merged=true` 只在选择范围的批次与来源映射通过复核后返回。全书 PDF 还需计划目标页等于原 PDF 全部物理页，全部批次完成并有效、合并报告覆盖同一集合；EPUB 全书需所有目标原生 spine 批次有效。报告 `status=needs_attention` 或 `quality_state=needs_review` 时只能说结构合并通过、仍待核验，不说“全书已完成”。重跑若中断，旧 staging 即使存在也必须被保存入口拒绝。

## 原子发布

在目标文件系统内构建完整 staging，锁定文献写者，验证所有文件与资产，并生成指纹。把完整候选原子落入新的 release，最后原子切换 manifest；不可逐个覆盖当前 release。任何失败保留最近有效指针和版本。

更换 source_revision 后不能让旧译本被误认作新原文的匹配译本；保留旧译本和版本绑定，按契约处理指针及下游 stale 信息。没有已接受的同步语义时不自行猜迁移。

生产发布器与故障恢复尚须实测，当前原型的单文件原子写入不是上述发布过程的完成证明。

## 独立保存和上游交付

独立转换的正常路径：开始时合并询问成品文件夹与是否继续翻译，未指定书名时提出默认名；已给出的选项直接沿用。确认目录/范围时合并为一次提问。随后连续处理和内部复核，不因普通疑难页逐项暂停。目标范围处理完成、校验通过后以 `save --layout split` 保存到开头指定的新文件夹：`阅读原文/` 为可读副本，`来源包/` 为完整可校验的转换包，`翻译输入/` 为默认生成的轻量增强型 MD 与交接索引，顶层另有与来源快照字节相同的原 PDF/EPUB 和 `文件说明.md`。若选择翻译，以 `来源包/` 和交接索引接续翻译 Skill，译文和对照成品放同级目录；未选择则不创建空翻译目录。翻译的五页试译需另经用户认可。非 MD 排版仅在用户明确选择该格式后进行。若路径始终未得到答复或权限阻断，保留内部产物并集中说明。最终单列仍有疑点的 PDF 文件页码、类型和已做的补救，不把待核验稿称作已校定原文。

保存完整原文/映射/资源与必要报告，核对新位置的相对链接，保留 document_id 与 source_revision。显示名只影响派生可读文件，内部仍为 source.md。已有同名文件默认另存，不静默覆盖；目标路径按实际权限执行。

上游调用时沿用其工作目录和已确认范围，不另弹保存选择，不逐批向最终用户通报。交付固定来源版本、实际范围、文件位置与报告，后续翻译和总体完成通知由调用方负责。
